# Site Levy — Portfólio pessoal

Portfólio pessoal de Levy Ponciano, web designer e desenvolvedor, criado para apresentar sua trajetória, seus serviços e seus projetos profissionais.

## Destaques

- Direção visual editorial e identidade própria
- Layout responsivo para desktop e dispositivos móveis
- Projetos, serviços, trajetória profissional e contato
- Navegação fixa com comportamento durante a rolagem
- Animações com suporte a preferência por movimento reduzido
- Imagem publicitária original criada para o projeto

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Executar localmente

Abra o arquivo `index.html` em um navegador ou use um servidor HTTP local.
